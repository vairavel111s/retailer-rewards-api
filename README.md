# Retailer Rewards API

A Spring Boot REST API project for calculating customer reward points
from purchase transactions.

## Technology

- Java 8
- Spring Boot 2.7.18
- Maven

Spring Boot 2.7.18 is used to meet the assignment's Java 8 requirement.

## Current status

The initial application setup is complete.
Reward calculation and REST endpoints are not implemented yet.

## Run locally

Open the project in IntelliJ IDEA and configure JDK 8 as the project SDK
and Maven runner JRE.

Reload the Maven project, then run:
com.retailer.rewards.RewardsApplication

The application starts on port 8080 by default.
